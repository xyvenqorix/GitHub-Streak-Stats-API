# 🔥 GitHub Streak Stats Generator

Generador de tarjetas de estadísticas de racha para perfiles de GitHub.

Esta aplicación permite crear y personalizar una tarjeta visual con las estadísticas de actividad de un usuario de GitHub y obtener el código necesario para integrarla fácilmente en un `README.md` o en una página web.

## ✨ Características

* 👤 Introducir cualquier usuario de GitHub.
* 🔥 Mostrar la racha actual.
* 📊 Mostrar el total de contribuciones.
* 🏆 Mostrar la racha más larga.
* 🎨 Seleccionar diferentes temas de colores.
* 🌈 Personalizar colores avanzados.
* 🖌️ Elegir fondo sólido o degradado.
* 📐 Personalizar el radio de los bordes.
* 🌍 Seleccionar el idioma/locale.
* 🔢 Activar o desactivar la abreviación de números.
* 📅 Excluir determinados días de la semana.
* 📆 Elegir entre frecuencia diaria o semanal.
* 🖼️ Generar la tarjeta en formato SVG.
* 🔗 Generar el enlace de la tarjeta para GitHub.
* 📝 Generar código Markdown para `README.md`.
* 🌐 Generar código HTML para páginas web.
* 📡 Consultar datos mediante JSON API.
* 📋 Copiar rápidamente los códigos generados.
* ⚡ Vista previa en tiempo real.
* 🎨 Personalización dinámica de propiedades y colores.
* 💾 Exportar la configuración del tema en formato PHP.

## 🎨 Temas disponibles

La aplicación incluye varios temas prediseñados:

* Default (Purple)
* GitHub Dark
* Radical Neon
* Tokyo Night
* Merko Cyber
* Gruvbox Dark
* One Dark
* Synthwave
* High Contrast

Además, los colores pueden modificarse manualmente desde la sección de personalización avanzada.

## 🧩 Integración con GitHub

El generador crea automáticamente el código necesario para utilizar la tarjeta en un perfil de GitHub.

### Markdown

Permite obtener directamente el código para colocar la tarjeta en:

```text
README.md
```

### HTML

También genera el código HTML para utilizarla en una página web.

### JSON

La aplicación puede mostrar los datos obtenidos mediante una salida JSON para utilizarlos en otros proyectos.

## 📱 Interfaz

La interfaz está diseñada para funcionar tanto en ordenador como en dispositivos móviles, con una vista dividida entre los controles de personalización y la vista previa de la tarjeta.

## 🚀 Uso

1. Introduce tu nombre de usuario de GitHub.
2. Selecciona el tema que prefieras.
3. Configura las estadísticas que quieres mostrar.
4. Personaliza los colores y el diseño.
5. Visualiza el resultado en tiempo real.
6. Copia el código Markdown o HTML generado.
7. Utiliza la tarjeta en tu perfil, README o sitio web.
